# Security Policy

## Supported Versions

Security fixes are provided for the latest F5-TTS release only. Update to the
latest release before reporting an issue.

| Version | Supported |
| ------- | --------- |
| 1.3.6   | :white_check_mark: |
| < 1.3.6 | :x: |

This table should be updated whenever a new release becomes the supported
version.

## Reporting a Vulnerability

Please report suspected vulnerabilities privately through
[GitHub's private vulnerability reporting for this repository](https://github.com/bolderfox12/F5-TTS/security/advisories/new).
Do not open a public issue or pull request for an unpatched vulnerability.

Include the affected version, the steps needed to reproduce the issue, and its
potential impact. Do not include API keys, passwords, access tokens, or other
secrets in the report.

You can expect an initial response within seven calendar days. If the report is
accepted, we will coordinate a fix and disclosure with you. If it is declined,
we will explain why when possible. We will provide updates as the investigation
progresses.

If the private reporting link is unavailable, open a GitHub issue only to ask
for a private contact channel. Do not include vulnerability details in that
issue.
