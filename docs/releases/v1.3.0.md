# F5 Studio v1.3.0

Create narrated stories with named characters, and use the web interface in your preferred language.

## Seven interface languages

Select **English**, **Português (Brasil)**, **Español**, **Français**, **Deutsch**, **简体中文**,
or **日本語** in the header. The preference is saved in the workspace and applies when the page reloads.
Messages are bundled locally, including microphone controls and training forms.
Your scripts, character names, saved voices, and model selections remain unchanged.

## Stories and characters

- Create a cast and assign each character a saved voice and registered model.
- Paste a script such as `Narrator: ...`, `Ana: ...`, and `Bruno: ...` to distribute dialogue automatically.
- Start from dialogue, YouTube, or short-drama examples, then edit, reorder, pause, or remove turns.
- Generate the full story, stop after the current turn, and reuse unchanged finished audio.
- Download the complete **WAV**, speaker-labeled **SRT**, and editable **TXT** for your production workflow.

The README now documents only the current Studio web workflow. Obsolete Gradio, legacy CLI,
and specialized runtime instructions were removed from the README; existing Studio features
such as saved voices, models, paragraph narration, transcription, and guided training remain available.

## Install or update

Install FFmpeg and the PyTorch build appropriate for your hardware, then install the release wheel:

```bash
python -m pip install "./f5_tts-1.3.0-py3-none-any.whl[studio]"
f5-tts_studio
```

Or update this checkout:

```bash
git pull --ff-only
python -m pip install -e ".[studio]"
f5-tts_studio
```

Open **http://127.0.0.1:7862** and keep using your existing workspace path.
See the [English README](https://github.com/bolderfox12/F5-TTS/blob/v1.3.0/README.md) for the complete guide.

No model weights are bundled. The original F5-TTS v1 Base + Vocos first download is approximately
**1.40 GB** if not already cached. Selecting an interface language does not require additional models.
Portuguese or other speech-language quality depends on your checkpoint and reference recordings.

**47 tests passed**, together with browser checks for all seven languages, story creation,
three reference voices, dialogue editing, WAV/SRT/TXT downloads, and saved-story preservation.
Synthesis in the new browser checks is simulated; the original-model GPU smoke test is documented separately.

Validation covers saved-data compatibility, character/voice/model routing, reusable dialogue,
subtitle timings, translation catalogs and placeholders, and browser workflows with simulated synthesis.
The interface language preference does not translate the spoken script or train a voice.
