# F5 Studio v1.2.0

This release brings the local Studio to the main branch, with English documentation,
microphone references, and a persistent library for your trained models.

## Highlights

- **Record a reference:** click **Gravar pelo microfone**, record up to 30 seconds, listen,
  and choose **Usar esta gravação**. FFmpeg converts it to mono 24 kHz WAV locally.
- **Keep multiple models:** register your Portuguese checkpoint and `vocab.txt` in **Meus modelos**,
  then select it in **Criar áudio** or **Regravar áudio**. The original English/Chinese model stays available.
- **Track your results:** generated-audio history records the model used for each output.
- **Avoid clipping:** signals above the PCM range are scaled before WAV export.
- **Use the full Studio:** narration projects, subtitles, local translation, audio tools,
  pronunciation rules, saved voices, and guided fine-tuning are included.

The Studio interface labels remain in Brazilian Portuguese. The README, changelog,
installation guidance, and these release notes are in English.

## Install

The attached wheel and source archive contain the application code, not model weights.
Install FFmpeg and a PyTorch build suited to your hardware, then install the wheel with the Studio extra:

```bash
python -m pip install "./f5_tts-1.2.0-py3-none-any.whl[studio]"
f5-tts_studio
```

Or install the exact release from source:

```bash
git clone --branch v1.2.0 https://github.com/bolderfox12/F5-TTS.git
cd F5-TTS
python -m pip install -e ".[studio]"
f5-tts_studio
```

Open **http://127.0.0.1:7862**. Follow the [README](https://github.com/bolderfox12/F5-TTS/blob/v1.2.0/README.md) for isolated
Python environments, Windows, WSL, CPU/GPU setup, recording, and model registration.
Python 3.12 is the locally validated setup; the package declares Python 3.11–3.15 support.

## Downloads and existing data

The initial F5-TTS v1 Base + Vocos download is approximately **1.40 GB**, in addition
to PyTorch/CUDA dependencies. Whisper and NLLB are separate downloads.
Your own trained checkpoints must be supplied separately.

Existing workspaces remain usable; continue launching Studio with the same workspace path.
Registering or switching models does not replace existing checkpoints.
The original English/Chinese model remains available alongside your registered models.

## Validation

- **36 tests and 14 subtests passed**, including all ten HTTP pages and real FFmpeg conversions.
- **Browser flow passed** with a simulated microphone: record, preview, release tracks, select,
  save a voice, show a simulated permission-denial error, register a checkpoint, and switch models.
- **Real synthesis passed** with the original F5-TTS v1 Base and Vocos on an RTX 3080 Ti/WSL2:
  English 6.848 s, Portuguese 8 s, both 24 kHz, finite, non-silent, and without PCM saturation.

Generating a valid Portuguese audio file does not establish pronunciation quality or validate
your private Portuguese model. Full fine-tuning and downloaded Whisper/NLLB quality were not tested.
TensorRT integration, performance-preserving voice conversion, and synchronized video dubbing
are not included in this Studio release.
