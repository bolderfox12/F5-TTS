# F5 Studio v1.3.5

This version expands voice fine-tuning into a multilingual workflow with BigVGAN, live training
monitoring, optional multi-GPU CUDA execution, and INT8 CPU export.

## Training workspace

- Import multiple recordings with Whisper segmentation or pair short files with a transcript manifest.
  Review and approve each example. New clips show RMS level and clipping.
- Extend the training vocabulary from approved transcripts while preserving the base token IDs.
  Fine-tune from a compatible public or custom checkpoint and evaluate held-out examples.
- Enable multiple GPUs to use all visible CUDA devices, or use one GPU. Optional mel spectrogram
  caching uses a bounded host RAM budget and shares that budget across training processes.
- Follow completed and planned updates, epoch progress, and logs. The resource monitor charts each
  GPU and its VRAM, CPU, RAM, training volume occupancy, and system reads and writes.
- Compare trained checkpoints with one reference and phrase. Register a version for inference or
  export an INT8 copy for a supported x86 PyTorch backend.

## BigVGAN and INT8

Select **F5-TTS Base · BigVGAN** for its matching SWivid acoustic checkpoint and NVIDIA's pretrained
24 kHz, 100-mel-band generator. Use an editable clone and initialize the NVIDIA submodule once.

```bash
git submodule update --init -- src/third_party/BigVGAN
```

INT8 exports quantize linear weights for CPU inference while preserving the vocoder precision.
Transfer the matching vocabulary with a custom checkpoint and select its original architecture when
registering it on another computer. The public F5-TTS v1 Base test export was about 355 MB from a
1.35 GB source. File size, speed, RAM use, and audio quality depend on the model and hardware.

## Update

```bash
git pull --ff-only
python -m pip install -e ".[studio]"
f5-tts_studio
```

Open **http://127.0.0.1:7862**. Keep the same workspace to retain local voices, models, and history.
Use the same GPU count and data settings to resume a run from its optimizer state. Create a separate
project to fine-tune from a prior checkpoint with new data or a different configuration.

## Verification

The suite passed 49 tests. Browser checks covered the training controls, resource charts, dataset
review, and INT8 export. Tests produced real audio using BigVGAN on one RTX 3080 Ti and an INT8
checkpoint on CPU. A synthetic two-process CPU run verified distributed training behavior.
Physical multi-GPU CUDA throughput was not measured.
