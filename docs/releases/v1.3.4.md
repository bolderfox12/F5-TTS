# F5 Studio v1.3.4

Train and manage F5 voice models with a dedicated GPU workflow, compare checkpoints, publish selected
versions for inference, and organize local audio files.

## Training workspace

The **Train a voice** page is divided into data review, training/GPU settings, checkpoint evaluation,
and inference publishing. Continue an existing project or create a separate experiment.

- Upload a compatible initial checkpoint and vocabulary, or use the cached F5 base checkpoint.
- Monitor GPU VRAM and, when available, utilization, temperature, and power.
- Configure frame batch size, maximum batch samples, gradient accumulation and clipping, CPU workers,
  mixed precision, 8-bit Adam, learning rate, warmup, epochs, and checkpoint retention.
- Compare several saved checkpoints with one fixed reference and sentence, record ratings, and save a
  reviewed generated sample as an optional voice reference.
- Register a checkpoint for Create audio without copying its weights. The training project and its
  checkpoints remain available in their original location.

The default profile sizes the F5 frame batch conservatively for the installed GPU. Use **Optimize for
this GPU** to apply the suggested mixed precision and optimizer settings; reduce the batch size if the
GPU runs out of memory. Training projects cannot change their base architecture or initial checkpoint
after their first training run.

## Model storage

**My models** shows registered models, checkpoint and vocabulary file sizes, and whether a model is
used by a saved story or narration. Managed checkpoint files can be removed after confirmation.
External model files are only deregistered; they are not deleted by the Studio.

## Local file library

**Files** lists generated audio, saved references, uploads, captions, and transcripts. Copying leaves
the original in place. Moving updates matching History, voice, narration, and transcript references.
Files copied outside the workspace remain listed in the library and can be moved or deleted there.
Deleting an in-use reference is blocked until the affected story or narration selects another voice.

## Installation and update

Install FFmpeg and the PyTorch build appropriate for your hardware, then install the release wheel:

```bash
python -m pip install "./f5_tts-1.3.4-py3-none-any.whl[studio]"
f5-tts_studio
```

Or update the checkout:

```bash
git pull --ff-only
python -m pip install -e ".[studio]"
f5-tts_studio
```

Open **http://127.0.0.1:7862** and keep using your existing workspace. Model weights are not included
in this release. If the F5 base model is not cached and no starting checkpoint is uploaded, the first
training run may download approximately 1.4 GB.


## Audio library improvements

- A clearer **Audio library** navigation item with search and category filters for generated speech, saved references, edited clips, uploads, and captions.
- In-browser waveform previews with duration and sample rate for supported audio formats.
- Select start and end points and save a cropped section as a new WAV; the source file stays intact.
- Save any library audio, including a cropped reference, to My Voices with its transcript.
- Portuguese, English, Spanish, French, German, Chinese, and Japanese labels for the new library controls.


## Speech export and interface polish

- Choose WAV or MP3 when generating speech, with high, standard, or compact output quality. WAV keeps the 24 kHz model rate at 24-bit or 16-bit PCM; compact WAV uses 16 kHz. MP3 uses 320, 192, or 128 kbps.
- Optional steady-noise reduction and stereo export. Stereo duplicates a mono voice to both channels.
- The new export pipeline runs after F5-TTS inference and stores the chosen output in History. MP3 export and noise reduction require FFmpeg.
- Animated, grouped navigation with an active-page highlight and reduced-motion support. Audio tools now include short explanations for each effect and its limits.


## Live generation dashboard

- Shows real F5 sampling-step progress by text chunk, followed by export progress and completion.
- Displays current CPU use, GPU use and VRAM, system RAM, drive space, and whole-system disk read/write rates while generation is running.
- Adds `psutil` to the optional Studio dependencies for CPU, memory, and disk telemetry. GPU utilization and VRAM are read from PyTorch and `nvidia-smi` when available.
