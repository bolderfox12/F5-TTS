# F5 Studio v1.3.6

- **Reference library.** Recent microphone recordings and audio references are available from Create audio after a page reload. Save a named favorite to reuse its audio and transcript across Studio sessions.
- **AI-assisted editing.** Ask Gemini, OpenAI, Claude, or a local Ollama model to refine a script for F5-TTS. Review and edit the suggestion before applying it. Gemini can optionally analyze and transcribe the reference audio. Local transcription, audio quality feedback, and waveform trimming are also available.
- **Voice per dialogue turn.** Assign saved voices or separate reference clips to individual parts of a script to control delivery and intonation, then export a single audio file.
- **Security.** Studio checks request hosts, origins, and upload sizes. Audio processing restricts FFmpeg inputs, checkpoint loading uses weights-only mode with patched PyTorch versions, and remote Gradio access requires credentials. Workspace metadata is written atomically, and local workspace files and secrets are excluded from the Docker build context.
- **Maintenance.** Removed superseded files, aligned the test suite with CI, and kept the README in English.

Validation covered 61 automated tests, browser checks for reference persistence, and CUDA synthesis. The standalone Docker and TensorRT environments have separate dependency stacks and need their own security review.
